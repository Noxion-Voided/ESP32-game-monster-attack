this project is for education and this the guide if you want to use.
Wiring Part	Connection
OLED SDA	GPIO21
OLED SCL	GPIO22
OLED VCC	3V3
OLED GND	GND
Left button	GPIO32 and GND
Right button	GPIO33 and GND
OK button	GPIO25 and GND
Guard button	GPIO26 and GND
